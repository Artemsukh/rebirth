# 다시 태어난다면

2026년에 태어날 아기 1억 3,250만 명, 또는 지금 살아 있는 83억 명 가운데 한 명으로 무작위로 다시 태어나 보는 페이지입니다. 나라, 성별, 나이가 실제 인구 구성에 비례해 정해지고, 그 사람이 받게 될 출발선(기대수명, 어릴 때 숨질 확률, 1인당 GDP 등)을 세계 전체와 나란히 보여 줍니다.

[RandomReincarnation](https://oters1117-art.github.io/RandomReincarnation/)에서 아이디어를 얻어 자료와 화면을 새로 만들었습니다.

## 원작과 달라진 점

- **범위:** 195곳에서 236곳으로 늘렸습니다. UN 세계인구전망 2024의 국가·지역을 모두 담았고, 인구 1,000명이 안 되는 교황청만 뺐습니다. 원작이 빠뜨린 아르메니아, 카보베르데, 홍콩, 마카오, 푸에르토리코 등에서는 한 해 약 15만 9천 명이 태어납니다.
- **코드:** 코소보를 UN 코드 412로 바로잡았습니다. 원작은 383을 써서 지도에 표시되지 않았습니다.
- **추첨:** 두 가지 기준이 있습니다. 출생아 기준은 나라와 성별을 뽑고, 인구 기준은 나라, 성별, 나이를 236 × 2 × 101칸에서 뽑습니다. 난수는 `crypto.getRandomValues`에서 53비트를 가져옵니다.
- **지표:** 나라마다 골라 적던 문구 대신, 모든 나라에 같은 기준의 지표를 붙였습니다. 기대수명, 돌 전과 다섯 살 전에 숨질 확률, 65세까지 살 확률, 1인당 GDP(환율 기준과 구매력 기준)입니다.
- **순위:** 나라 수가 아니라 사람 수로 셉니다. "상위 7%"는 같은 해에 태어나는 같은 성별 아기 가운데 이 나라보다 지표가 좋은 나라에서 태어나는 아기가 약 7%라는 뜻입니다.
- **지도:** Natural Earth 1:5천만 경계를 씁니다. UN 통계 단위에 맞추려고 프랑스 해외 레지옹과 카리브 네덜란드를 본국에서 떼어 냈습니다.

## 자료

| 항목 | 출처 |
|---|---|
| 출생아, 인구, 성비, 사망률, 합계출산율 | UN World Population Prospects 2024, 중위 추계 2026년 (CC BY 3.0 IGO) |
| 기대수명, 사망 확률, 남은 기대여명 | 위 자료의 2026년 성별·한 살 단위 사망률로 직접 계산한 생명표 (UN 발표 기대수명과 0.02년 안쪽으로 일치) |
| 1인당 GDP | IMF World Economic Outlook, 2026년 4월판의 2025년 추정치 (Worldometers 정리표 경유). IMF 값이 없는 곳은 세계은행이나 UN 값을 쓰고 표시함 |
| 지도 | Natural Earth (퍼블릭 도메인), world-atlas 경유 |

1인당 GDP는 두 값을 함께 적습니다. 큰 숫자는 시장 환율로 바꾼 미국 달러이고, 순위도 이 값으로 매깁니다. 작은 숫자는 물가 차이를 걷어 낸 구매력평가(PPP) 기준 국제달러입니다. 예를 들어 한국은 36,227달러와 65,405국제달러, 인도는 2,675달러와 11,789국제달러입니다.

## 폴더 구조

```
index.html        빌드 결과물. 이 파일 하나로 동작합니다.
build.py          src/, data/, vendor/를 index.html 하나로 합칩니다.
src/              body.html(구조), style.css(모양), app.js(동작)
data/             appdata.json(가공된 인구·경제 자료), world.topo.json(지도)
vendor/           topojson-client 3.1.0 (ISC 라이선스)
pipeline/         data/를 만든 스크립트와 GDP 원표. 기록용이며, UN 원자료는 wpp2024 R 패키지에서 받아야 다시 돌릴 수 있습니다.
```

## 고친 뒤 다시 빌드하기

```bash
python3 build.py
```

외부에서 불러오는 것은 d3 7.9.0(cdnjs, 실패 시 jsDelivr)과 Google Fonts(Hahmlet, IBM Plex Sans KR)뿐입니다. d3를 불러오지 못해도 추첨과 표는 작동하고, 지도 자리에 안내 문구가 나옵니다. 기록은 브라우저의 localStorage에만 저장됩니다.

## GitHub Pages로 공개하기

저장소의 Settings → Pages에서 Source를 "Deploy from a branch", Branch를 `main`, 폴더를 `/ (root)`로 고르면 `https://<사용자명>.github.io/<저장소명>/`에서 열립니다.

## 한계

- 2026년 값은 모두 추계입니다. 추계 뒤에 벌어진 전쟁이나 재난은 반영되지 않았을 수 있습니다.
- 나라 평균은 나라 안의 격차를 가립니다. 같은 나라라도 지역, 소득, 도시와 농촌에 따라 출발선은 크게 다릅니다.
- 1인당 GDP는 평균 생산량일 뿐 분배를 말해 주지 않습니다. 환율 기준으로 코소보, 레위니옹, 저지섬 등 18곳은 IMF 값이 없어 비워 두었습니다.
